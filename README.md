# NHANES lifestyle factors and all-cause mortality

Does smoking, physical activity, alcohol consumption and body mass index predict all-cause mortality among US adults aged 20 and over? This project uses NHANES 2007-2014 linked to the NCHS public-use mortality files (follow-up to 31 December 2019).

## Pre-specification

The analysis plan, DAG and adjustment sets were committed and tagged `plan-v1` before any outcome data were accessed. Any later change is recorded in `DEVIATIONS.md`.

## Files

- `analysis_plan.md`: pre-specified analysis plan
- `dag.R`: DAG and exposure-specific adjustment sets
- `dag.png`: DAG figure
- `adjustment_sets.txt`: output of the adjustment set calculation
